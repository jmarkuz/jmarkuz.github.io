# Keywords for Senior Java Developer searches

## How this list was made

Synthesised from web searches over several sources (job descriptions and role guides for Senior Java Developer, recruiter Boolean-search guides, and Prague / EU postings). It is **not a measured frequency count**: most individual job pages could not be loaded (closed, blocked or JavaScript-only), so no percentages are claimed.

Recruiter search patterns seen in the sources:
`("Java developer" OR "Java engineer" OR "backend developer") AND (Spring OR Hibernate OR Microservices) AND (AWS OR Azure) NOT intern`
`(Java OR Kotlin) AND ("Spring Boot") AND (PostgreSQL OR MySQL)` and `Java AND Spring AND Kafka`.

## Keywords and where they appear on the site

| Group | Keywords | Where |
|---|---|---|
| Title | Senior Java Developer, Senior Java Software Engineer; Senior Java Backend Engineer and Senior Backend Engineer in metadata and JSON-LD only | `<title>`, description, hero, status, contact, JSON-LD `jobTitle` |
| Core | Java 17 / 21, Spring Boot, Spring Cloud / Data / Security, Hibernate, JPA, microservices, REST APIs, distributed systems, high-load, concurrency / multithreading, system design, event-driven | hero, core-stack chips, experience text, skills, filters |
| Messaging | RabbitMQ, ActiveMQ, WebSocket, event-driven; Kafka (personal projects only) | experience, skills, Messaging filter |
| Data | SQL, PostgreSQL, Redis, MongoDB, Elasticsearch, NoSQL, Bucket4j (rate limiting) | experience, skills |
| Cloud / DevOps | Kubernetes, Docker, AWS, Azure, GCP, CI/CD, GitLab CI/CD, Terraform, Helm, Vault, Bazel, Datadog | experience, skills, Cloud & DevOps filter |
| Quality | TDD, JUnit, Mockito, Testcontainers, SonarQube, code review, 80%+ coverage | hero (Practices), about, experience, skills, Quality filter |
| Practices | Agile / Scrum, code review, mentoring, technical design | hero (Practices), about, skills, Team leadership filter, Brightfin experience |

All roles are also rendered as plain text ("Experience in plain text"), so search engines, ATS parsers and Ctrl+F see the full history, not only the company selected in the interactive trace.
